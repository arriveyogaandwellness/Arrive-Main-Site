# 📁 Page Assets Directory Structure

This directory is organized on a per-page basis to make updating and maintaining website imagery simple.

## How to Change Images on Any Page:
1. Navigate to the folder of the page you want to modify (e.g. `public/assets/pages/home/` or `public/assets/pages/about/`).
2. Replace any image file with your new photo using the **same filename**, OR drop a new image in the folder and update the corresponding `src` attribute in that page's HTML file (e.g. `public/about.html`).
3. Refresh your browser to see the new imagery immediately!
