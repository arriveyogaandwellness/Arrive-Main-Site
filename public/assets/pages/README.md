# 📁 Authentic Page Assets Directory Structure

All imagery across the Arrive Sanctuary website is strictly sourced from authentic client materials located in `Retreat Website Docs` (including authentic property photography, founder media appearances, printed SWAY restaurant menus, and original artwork).

## 🚀 Easy Site Maintenance — How to Update Images:
1. **Per-Page Organization**: Every page has its own dedicated folder inside `public/assets/pages/` (e.g. `home/`, `accommodations/`, `dining/`, etc.).
2. **Updating an Image**: Replace any image file using the **same filename**, OR drop your new image into the respective page folder and update the `src` in the corresponding HTML file.
3. **Instant Preview**: Changes take effect immediately upon browser refresh (or restart of the Node server).
